# Week 7 demo script — target 90 seconds

## Setup

Preload two realistic synthetic exports so the app has:
- several matching SKUs
- one high-value quantity mismatch
- one stale source
- one low-value mismatch

## Demo

**0–15 sec — problem**
"Retailers often already have inventory software. The issue we found is that when connected systems disagree, owners and staff still spend time working out which number they can trust."

**15–30 sec — dashboard**
Show inventory health, open issues, high-risk count.

**30–50 sec — exception**
Open the high-risk SKU.
Show:
- source A quantity
- source B quantity
- freshness
- value at risk
- confidence score

**50–65 sec — explanation**
Generate / show explanation and recommended check.
State: "AI does not decide the correct quantity. It explains the evidence and directs the investigation."

**65–80 sec — resolution**
Enter verified physical count and resolution method.
Click Resolve.

**80–90 sec — outcome**
Return to dashboard. Open-issue count decreases and audit trail exists.

## Key line

"Your inventory system tells you the stock number. StockTrust tells you whether you can trust it."
