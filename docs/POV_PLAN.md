# Proof of Value plan

## Objective

Prove that StockTrust reduces the effort required to identify and resolve meaningful inventory discrepancies, while increasing user confidence in the evidence used to make inventory decisions.

## Round 1 — Founder test

User: retail founder / owner.

Tasks:
1. Find which records need attention using the current process.
2. Resolve one selected discrepancy using the current process.
3. Repeat with StockTrust.

Capture:
- time to first meaningful discrepancy
- time to resolution
- number of tools/files/screens checked
- errors / missed discrepancies
- confidence (1–5)
- usefulness (1–5)
- quotes

## Round 2 — Employee test

Test whether the interface can be used without the founder explaining it.

Key question:
> Can an employee investigate and document the next step without escalating immediately to the owner?

## Round 3 — External retailer

Repeat with a retailer outside the initial business.

Purpose:
- test whether the problem generalises
- identify different source systems / workflows
- stress-test terminology and severity logic

## Traceability table

Maintain this throughout the term:

| User evidence | Design implication | Change made | Retest result |
|---|---|---|---|
| Example: "I don't care about $5 mismatches" | severity must consider materiality | added value-at-risk thresholds | TBD |

## Minimum evidence for Week 10

- at least 2 testing rounds
- preferably >1 business
- before/after metric
- at least one design change caused by feedback
- one feature deliberately rejected because evidence did not justify it
